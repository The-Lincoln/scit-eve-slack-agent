# SCITBD AI CEO Daily Operational Plan (BST / UTC+6)

## Block map

- **Block 1 (06:00–12:00 BST) | South Asia & Domestic** — SEO + local content deploy; BD/e-GP RFP scrapers → Proposal Factory; lead-nurture touches 1–3 + CRM; brand SLA audit (Trustpilot/GMB, <1h escalation on negative).

- Support ticket <2h → auto-route. Inbound RFP → proposal <2h via Proposal Factory.
- Lead ≥$10,000 → CEO video within 24h. Negative review → CEO queue <1h. NPS <40 → emergency review <48h. Uptime 99.9%.

When asked "what now?", resolve current BST block first, then answer with that block's tasks + open items only.
